# Dashboard Design

## Page 1 — Executive Fraud Overview
- KPI cards for total transactions, fraud count, fraud rate, total amount
- Simple bar chart for fraud vs legitimate counts
- Transaction amount distribution chart
- Summary note about risk concentration

## Page 2 — Transaction Risk Analysis
- Time-band fraud rate chart
- Amount-band traffic and fraud rate
- Distribution of amount by class
- Feature-level comparisons

## Page 3 — Model Performance
- Precision, recall, F1, average precision, ROC-AUC
- Confusion matrix
- Precision-recall curve (if imported)
- Selected threshold summary

## Page 4 — Alert and Risk Operations
- Flagged vs non-flagged transaction counts
- False-positive and false-negative counts
- Amount associated with false positives and missed fraud
- Threshold trade-off chart

## Visual design guidance
- Use a calm executive color palette.
- Label all percentage and amount fields correctly.
- Keep the fraud interpretation clearly descriptive rather than causal.
